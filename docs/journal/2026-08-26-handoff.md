## The workarounds you must know about

This seat's egress proxy blocks HuggingFace, so fastembed can't
download the semantic model. Two documented workarounds exist and were
used this arc:

1. **`docs/embedder-stand-in.md`** + **decisions 0084/0089** — this
   very LLM answers `score(a, b) → float` per pair against a rubric.
   Bounded strictly: measuring instrument, NOT a backend. Never keys
   the cache, never behind a seal. 0.150 mean spread across
   independent instantiations, 0.300 max — treat every number as a
   lower bound.
2. **`bench/bench_decision_n1.py --scores <json>`** — reads a
   precomputed `{probe_id: {cand_id: sim}}` map. Two artifacts on disk:
   `bench/corpus_decision_n1/semantic_scores.json` (24 decisions,
   pre-existing) and `bench/corpus_arc_questions/semantic_scores.json`
   (10 arc probes, added this arc). Both replay in seconds with no
   network.

**The trap this arc hit:** I marked decision 0198 Q2 as "deferred to a
seat with network access" in the first commit — the operator caught
that both workarounds were already in the tree and unused. Extended
the commit before merge with real numbers. **Check for a documented
workaround before writing "deferred."**

## What you must not do

- **Seal anything** (`status="sealed"`, `verifier="<a human's name>"`).
  The covenant. The seat rule the whole tree exists to enforce.
- **Change a default matcher, engine, or fallback bar** without a new
  measurement and a recorded decision — even if a test passes.
- **Skip, disable, or quarantine a test** to get CI green. The `babysit/
  steward` rules and `.claude` reminders are explicit about this.
- **Push before running `bash scripts/ci-lint.sh` and `pytest -q` on
  the surface you touched.** One validated push beats three
  speculative ones.
- **Assume "already deferred" == "no measurable path exists."** Check
  `docs/embedder-stand-in.md`, `bench/`, `scripts/corpus/`, and the
  probe reports first. Nestor's own store is often the first place to
  ask.
